Component library

220+ HTML & CSS components, ready to drop on a page

The openconstructor library is a set of hand-made components written in plain HTML and CSS — no framework, no build step. Click one to place it on the free-form canvas, restyle it, ask the AI to change it, and export the result.

How to use them

  • Browse with live previews. Hover a card in the side panel to see it animate; type in the search box to find anything across all sections.
  • Place freely. The canvas is free-form: drag elements anywhere, pan and zoom, and set the page background in the background editor.
  • Edit the code. Right-click any element to view and change its HTML and CSS, or add your own snippet with + custom code.
  • Change with AI. Select an element and describe the change, or use ⚗ Fusion to give one component the style of another. See the AI guide.

Export anywhere

A page built from these components exports as standalone HTML, as a React, Vue or Svelte component, or — for games — as a Roblox Luau script or a LÖVE 2D main.lua.

FAQ

Are the components free for commercial use?

Yes. You can use them in personal and commercial projects. The project is open source under the MIT license; a few components are adapted from other open-source libraries, credited in the repository.

Do the components depend on a framework?

No. Each one is plain HTML and CSS, so they work in any stack.

Can I add my own components?

Yes. Use “+ custom code” to paste any HTML and CSS; it becomes an element on the canvas like the built-in ones.
