FAQ

Is this template free?

Yes. The template and the editor are free and open source (MIT). You can use the result in personal and commercial projects.

Do I need to know how to code?

No. Open the template, then type what you want changed — “make it a bakery in Lisbon”, “change the accent to green” — and the AI rewrites the page. You can also edit any text or the HTML and CSS by hand.

Can I publish it on my own domain?

Yes. Publish in one click to a free openconstructor.pw link, connect your own domain, or export a static HTML site or a React / Vue / Svelte project.

Does it work on phones?

Yes. The sections are responsive and stack into one column on small screens.
