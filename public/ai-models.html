Free AI models for building websites

Every free text model on Groq and OpenRouter got the same two tasks from the openconstructor editor: build a coffee-shop landing page, and answer a short CSS question. We measured the time, checked the answer format and looked at the result.

Best designQwen 3.8 27B · Groq

Clearly the nicest pages. On the free plan — about one page a minute.

Fast & reliableGPT-OSS 120B · Groq

A full page in ~2 seconds, never broke the format. What the free AI uses first.

Best on OpenRouterNemotron 3 Ultra 550B

Polished result with icons; takes ~40 seconds.

How it was tested

  • The editor's own instructions: a one-line JSON header, then the HTML and CSS in one code block; questions answered as text, without building anything.
  • One attempt per model and task, low reasoning effort where supported, up to 8,000 output tokens, pauses between requests.
  • “Format” means the answer could be placed on the canvas (or shown as text for the question) without a retry.
  • Free tiers change often: models appear, disappear and get rate-limited. Groq removed Llama 3.3 70B before this test.
